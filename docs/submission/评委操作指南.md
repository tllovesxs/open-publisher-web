# 评委操作指南

## 1. 无账号体验（约 3 分钟，无模型成本）

启动后访问用户端 http://localhost:5173。进入“文章”，打开公共示例《把零散想法变成一篇清晰的文章》，切换编辑、分栏、预览；修改后保存，查看本机版本。公共原稿不被覆盖。

进入“模板”，查看公共模板骨架，选择“复制另存”，修改并保存；进入“素材库”查看原创示例图，也可上传测试图片。匿名编辑和上传保存在本浏览器；清理浏览器存储会影响本机数据，登录后不会自动迁移。

点击设置或 AI 操作会弹出登录；选择取消或按 Escape，检查当前输入仍在。成功登录后也需再次点击 AI 按钮，不自动产生模型调用。

## 2. 隔离 Mock 演示

必须在独立克隆目录和独立 Compose 项目中演示，避免改动日常数据库模型配置。Compose 文件包含固定 container_name 与端口，如同机已有服务，应在独立机器或明确修改演示副本的容器名、端口后运行；仅更换 -p 不能消除固定容器名冲突。

复制 .env.example 到 .env，配置数据库、JWT、管理员密码和 Fernet 主密钥。再执行：

```powershell
docker compose -f docker-compose.yml -f docker-compose.mock.yml up -d --build
```

在管理后台 http://localhost:5174 以环境中自行设置的管理员登录；新建测试文本模型档案：接口 http://mock-llm:8001/v1，模型 mock，Key 为无价值演示值 mock-local-only，启用 tools 能力并作为默认。Key 经数据库密文保存。不要录入真实上游密钥，不修改真实部署的默认档案。

用户端注册独立测试用户或使用管理员账号，选择该 Mock 档案。关闭联网、真实生图和不相关节点，输入“依据已给产品事实写一篇推广推文”，生成后查看节点、正文、版本。Mock 返回固定内容，不代表模型质量和实时信息。risk 节点由本机脚本返回 low；真实 SDK 流式与 write_article 工具传输由 test_mock_transport 验证。

## 3. 登录后的功能核对

| 操作 | 预期 | 失败处理 |
|---|---|---|
| 创作、观察流式、切换页面再返回 | 节点状态和正文继续显示 | 查看运行错误，保留上下文，不连续点击付费重试 |
| AI 修改并保存 | 新修订，历史仍可查看 | 并发 409 时重新读取并比较 |
| 恢复旧版本 | 生成新的恢复修订 | 不改动旧历史文件 |
| 配图规划并取消 | 不自动落稿 | 用户确认后才应用；本轮无需真实生图 |
| 上传图片后拖到编辑或预览 | 按落点插入，原图移动不重复 | 取消拖拽应保留待插入素材 |
| 风险 unknown / medium | 同步前要求人工确认 | 核对事实、隐私、版权后再勾选 |
| 当前修订风险 high | 应用同步按钮阻断 | 修改并重新检查，不绕过按钮 |

## 4. 发布体验

无扩展可查看同步说明与纯净预览，不能证明真实平台写入。自动化 smoke-sync-safety 使用本机桥替身展示 high 阻断、unknown 确认和 low 提交，不联系平台。

真实草稿同步需另在 Chrome/Edge 安装 WechatSync、允许本站访问、刷新并登录目标平台。仅在用户明确授权实际发送时选择专用测试平台和草稿；确认同步记录和草稿箱。超时或 unknown 先核对远端，避免重复提交。正式发布由平台内人工确认。应用预检不控制扩展自己的右键提取功能。

## 5. 证据与限制

RAG 需同时看到资料、命中片段/来源编号、节点记录与正文，降级原文注入不算向量命中。当前索引是单进程 JSON，不代表多实例部署能力。真实 Vision、生图、嵌入、排序以及外部平台不在本轮额外付费验收范围。

团队、公开地址和评审账号按用户要求暂不填写；本指南没有可复用的真实密码。
