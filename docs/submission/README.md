# 比赛评审材料索引

更新日期：2026-10-30。产品定位：**面向产品推广与内容运营的 AI 推文创作及发布工作台**。这里的“推文”包括平台推广图文，不将产品限定为 Twitter/X 的短文本。界面沿用“文章”作为稿件与版本对象的名称。

## 材料入口

| 文件 | 用途 |
|---|---|
| [技术方案](技术方案.md) | 概述、需求、架构、AI 方案、实现、安全、测试、部署及商业分析 |
| [评分证据矩阵](评分证据矩阵.md) | 按六大维度和细分项映射代码、自动化及演示证据 |
| [评委操作指南](评委操作指南.md) | 无账号浏览、隔离 Mock、登录后操作和异常处理 |
| [演示脚本](演示脚本.md) | 可现场演示的操作顺序与讲解；不含视频成品 |
| [部署与提交清单](部署与提交清单.md) | 本地启动、生产校验、验收、冻结与提交边界 |
| [验证记录](验证记录.md) | 本轮实际运行的命令、结果及未验证部分 |
| screenshots/ | 隔离浏览器从真实本地公共示例采集的页面截图 |
| ../../output/pdf/技术文档.pdf | 由技术方案排版生成的 PDF（上限 30 页） |

评分权重与提交格式沿用工作区 `WORKLOG.md` 的赛事记录；本轮未重新核验赛事官网，不将内部自评等同官方得分。

团队名称、成员分工、联系方式、公开演示地址、评审账号按用户要求暂不填写。未公开部署，也未替用户提交比赛或推送远程。
