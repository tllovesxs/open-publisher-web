# 稿流评审材料

面向产品推广与内容运营的 AI 推文创作及发布工作台。平台将资料研究、大纲规划、正文编辑、配图、版本管理与草稿同步组织在同一工作台，支持产品发布、功能更新和开源推广等图文场景。
