# 现场演示脚本

时长约 6 分 30 秒。以一次产品更新推广为主线，展示从产品事实到推广稿件，再到配图和草稿同步的操作过程。使用 Mock 时在画面中标注 Mock；固定响应用于接口与交互演示。

| 时间 | 操作 | 讲解重点 | 展示内容 |
|---|---|---|---|
| 0:00–0:35 | 打开创作页 | 产品推广需要事实、受众与行动入口 | 创作要求与资料输入 |
| 0:35–1:15 | 浏览稿件、模板与素材 | 先体验编辑，AI 操作按需登录，取消保留输入 | 公共示例与模板另存 |
| 1:15–2:25 | 输入产品事实并开始创作 | 资料研究、大纲与正文按阶段推进 | 节点状态、流式正文、write_article 与版本事件 |
| 2:25–3:10 | 查看来源与检查结果 | 核对资料引用及审阅意见 | research、来源编号与风险报告 |
| 3:10–3:55 | 修改、保存并恢复历史 | 手动编辑和 AI 修改都保留版本 | 修订列表与恢复后的新版本 |
| 3:55–4:40 | 查看配图方案、上传与拖入图片 | 用户确认素材和位置后应用 | 配图栏、正文落点与移动去重 |
| 4:40–5:25 | 展示同步前检查 | 高风险阻断，中风险与待确认状态要求人工确认 | 风险状态、确认项与草稿同步入口 |
| 5:25–6:00 | 介绍架构与 AI 方案 | Writer 编排、LangGraph 候选改写、RAG 和工具调用 | 技术方案第 3–8 节 |
| 6:00–6:30 | 测试与应用价值 | 330 项后端测试、双前端构建与主要浏览器操作覆盖 | 验证记录与评分证据矩阵 |

## 开场讲解

“产品推广常常需要在资料、写作、配图和发布工具之间来回切换。Open Publisher Web 把这些操作放进同一个工作台：先整理产品事实和读者需求，再生成结构与正文，最后完成编辑、配图和草稿同步。”

## 收尾讲解

“这份稿件保留了资料来源、生成过程和修改版本。用户可以调整正文、恢复历史、确认配图，并在目标平台的草稿箱完成最终发布。模板和素材还能继续复用，方便后续的产品更新与内容运营。”
