# 部署与材料整理

## 本地启动

1. 安装 Docker 与 Compose，检查 5173、5174、8000、33061 和 6379 端口。
2. 复制 .env.example 为 .env，设置数据库密码、JWT、管理员密码和 Fernet 主密钥。
3. 执行 docker compose up -d --build，启动时自动执行 Alembic 迁移。
4. 检查 http://localhost:8000/api/health，确认 status、database、redis 状态正常。
5. 打开用户端与管理端，在管理端配置模型档案和集成 Key。API Key 通过 Fernet 加密后保存于数据库。

## 环境配置

| 配置项 | 部署设置 |
|---|---|
| APP_ENV | 对外部署设置为 production，启动时执行配置校验 |
| JWT 与管理员密码 | JWT 至少 32 字符，管理员密码至少 12 字符，使用独立生成的值 |
| SECRET_ENCRYPTION_KEY | 使用有效 Fernet Key，通过环境注入，并与数据库分别备份 |
| 数据库与 Redis | 使用强密码，限制为服务内部访问 |
| 访问入口 | 使用 TLS 反向代理，配置实际 API 地址、同源访问与 CORS |
| RAG 索引 | 采用单写入进程配置，索引写入使用互斥和原子替换 |
| 账号与数据 | 为演示配置专用账号与额度，公开截图使用公共示例 |

## 质量检查

在 backend 目录运行：

~~~powershell
python -m pytest tests -q -p no:cacheprovider
~~~

在 frontend 与 frontend-admin 目录分别运行 npm run build。在 frontend 目录配置 PLAYWRIGHT_MODULE、SMOKE_BROWSER_PATH、SMOKE_BASE_URL 后运行主要浏览器脚本：

~~~powershell
node scripts/smoke-public-examples.cjs
node scripts/smoke-workspace-login.cjs
node scripts/smoke-writer-stream.cjs
node scripts/smoke-image-drag.cjs
node scripts/smoke-sync-safety.cjs
node scripts/review-evidence.cjs
~~~

浏览器脚本采用隔离测试环境，同步风险场景使用本机桥替身。测试结果与性能采样见验证记录。

## 材料生成与整理

安装 reportlab 与 Pillow 后，执行 python scripts/build_submission_pdf.py。脚本读取 docs/submission/技术方案.md，生成 output/pdf/技术文档.pdf，附录包含工作台截图。

提交材料包含技术文档 PDF、技术方案、评分证据矩阵、评委操作指南、演示脚本、验证记录与界面截图。整理归档时记录代码 commit、PDF SHA256、依赖版本和材料列表，便于复现。归档范围排除 .env、数据库、临时目录、依赖目录、运行日志及私人数据。
